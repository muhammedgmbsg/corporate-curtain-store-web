# Corporate Showcase and E-Commerce Web Application for Erol Perde

This repository contains the official frontend and backend source code for the corporate web application developed for Erol Perde, a well-established home textile and mechanized curtain systems store. 

The project aims to digitize the brand's physical store presence by providing an elegant online catalog, service descriptions, detailed product categories, and seamless customer communication channels.

## Overview

Traditional home textile retail relies heavily on in-store custom design consultations. This application bridges that gap by offering a modern, accessible web application where customers can explore premium curtain systems, request measurements, and contact the business directly.

* **Product Catalog:** Showcases comprehensive product lines including motorized blinds, zebra curtains, vertical PVC systems, wooden/metal venetian blinds, and luxury home textiles.
* **Corporate Identity:** Includes dedicated sections for company history, customer satisfaction guarantees, quality assurance policies, and free on-site measurement/estimation services.
* **Responsive Architecture:** Fully optimized for desktops, tablets, and smartphones to ensure a smooth browsing experience for all clients.
* **Contact & Location:** Features dynamic contact forms, interactive maps, operating hours, and direct call/email integrations for local operations.

## Key Features

* **Advanced Categorization:** Well-structured filtering for home decoration, office blinds, and advanced automated mechanical systems.
* **Interactive Media Showcase:** High-resolution galleries displaying finished interior architecture projects, custom installations, and material patterns.
* **Service Highlight Modules:** Built-in call-to-actions emphasizing key corporate benefits such as Free Estimation and Measurements.
* **Contact Management:** A robust backend/form handling mechanism that routes user inquiries and appointment requests straight to store representatives.

## Technology Stack

The project is built using a modern stack designed for fast loading times, search engine optimization (SEO), and clean component architectures:

* **Frontend:** HTML5, CSS3, JavaScript (or Framework of choice e.g., React / Vue / Next.js)
* **Styling & UI:** Responsive frameworks (Bootstrap / Tailwind CSS) ensuring clean grid systems and cross-browser compatibility
* **Backend Operations:** Server-side scripts to process customer inquiry forms and dynamic content injection
* **Database/Data Store:** Storage solution for archiving store items, configuration types, and user messages

## Folder Structure

* `public/`: Assets, images, icons, and structured brand identity files.
* `components/`: Reusable interface components (navigation bar, product cards, footer, contact layout).
* `pages/`: Individual web page templates (Home, Products, About Us, Contact).
* `api/`: Endpoint configurations for message delivery, mail triggers, or database interactions.
